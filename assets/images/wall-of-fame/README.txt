Place images for the wall-of-fame section here.

Supported: .webp (preferred), .jpg, .jpeg, .png, .gif, .svg

Exact web path to use in HTML or admin photoUrl:
  /assets/images/wall-of-fame/YOUR-FILENAME.webp

Examples:
  /assets/images/wall-of-fame/my-photo.webp
  /assets/images/wall-of-fame/student-name-2025.webp

Always start with / so the image works on every page (/, /gallery, /about, …).
