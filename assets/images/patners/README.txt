Place images for the partners section here.

Supported: .webp (preferred), .jpg, .jpeg, .png, .gif, .svg

Exact web path to use in HTML or admin photoUrl:
  /assets/images/partners/YOUR-FILENAME.webp

Examples:
  /assets/images/partners/my-photo.webp
  /assets/images/partners/student-name-2025.webp

Always start with / so the image works on every page (/, /gallery, /about, …).
