Place images for the misc (logo.webp, favicon.webp) section here.

Supported: .webp (preferred), .jpg, .jpeg, .png, .gif, .svg

Exact web path to use in HTML or admin photoUrl:
  /assets/images/misc/YOUR-FILENAME.webp

Examples:
  /assets/images/misc/my-photo.webp
  /assets/images/misc/student-name-2025.webp

Always start with / so the image works on every page (/, /gallery, /about, …).
